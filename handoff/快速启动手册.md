# 快速启动手册

## 1. 目标

这份手册只保留最短可执行步骤，用于：

- 最快验证云服务器是否正常
- 最快完成一次实板烧录和联调

## 2. 最快验证服务器

先看健康检查：

```bash
curl -sS http://<CURRENT_BASE_URL>/healthz
```

预期：

```json
{"api":"ok","redis":"ok","sqlite":"ok","asr":"ok","llm":"ok","tts":"ok"}
```

## 4. 最快烧录喵伴板子

当前默认基线：

- 开发板：`ESP-VoCat v1.2`
- 核心模组：`ESP32-S3-WROOM-1`
- 工具链：`ESP-IDF 5.5.4`
- 触发方式：`触摸屏`

基础规格速记：

- `ESP32-S3`，`Xtensa` 双核 32 位 `LX7`
- `2.4GHz Wi-Fi (802.11b/g/n)`、`Bluetooth 5`
- `Flash` 最大可选 `16MB`
- 当前板卡确认 `PSRAM=16MB`
- 最多 `36` 个 `GPIO`

## 5. 先填配置

编辑：

- `esp_idf_demo/main/config.h`

至少填：

- `DEMO_WIFI_SSID`
- `DEMO_WIFI_PASSWORD`
- `DEMO_SERVER_BASE_URL`
- `DEMO_DEVICE_ID`

推荐值：

- `#define DEMO_SERVER_BASE_URL "http://<CURRENT_BASE_URL>"`
- `#define DEMO_DEVICE_ID "miaoban-v1p2-001"`

## 7. 串口优先看什么

启动时先看：

- `Runtime config`
- `Wi-Fi connected`
- `Initialized ESP-VoCat v1.2 touch trigger`

触摸后再看：

- `Touch trigger event: x=... y=...`
- `stage=record`
- `stage=upload`
- `stage=poll`
- `stage=download`
- `stage=play`
- `pipeline result=ok`

如果联调的是 `v3/realtime`，还要额外看：

- `session_id`
- `audio_connect_ms`
- `first_audio_byte_local_ms`
- `playback_start_ms`
- `http_status`
