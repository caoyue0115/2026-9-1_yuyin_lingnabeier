# 稳定交接包说明

## 1. 目标

这份说明用于明确“当前什么内容算稳定交接资产”，以及拿到交接包后应该先看什么。

## 2. 当前稳定交接范围

当前稳定可交接的内容包括：

- 设备端参考工程：`esp_idf_demo/`
- 云端接口契约：`/api/v2/tasks -> poll -> audio_url`
- 硬件联调说明
- 快速启动和排障文档

当前不作为稳定交接范围的内容：

- `20260409` 下的低延迟 `v3/realtime` 方案
- 本地调试目录：`.venv/`、`tmp/`
- 本地 bug 日志：`bug*.txt`
- 构建产物：`build/`
- 组件缓存：`managed_components/`

## 3. 当前稳定设备端能力

设备端当前已经稳定具备以下能力：

- 触摸屏触发
- 固定 `4` 秒录音
- 原始 PCM 上传
- 轮询任务状态
- 下载返回 WAV
- 板载喇叭播放
- 阶段化串口日志

## 4. 当前稳定配置基线

- 开发板：`ESP-VoCat v1.2`
- 核心模组：`ESP32-S3-WROOM-1`
- 工具链：`ESP-IDF 5.5.4`
- 目标芯片：`esp32s3`
- 服务地址：`http://<CURRENT_BASE_URL>`
- 设备 ID 示例：`miaoban-v1p2-001`

## 5. 推荐交付内容

如果要发给硬件同事或接手同事，建议交付：

- `esp_idf_demo/`
- `handoff/`

推荐压缩包名称：

- `stable_handoff_2026-04-09.tar.gz`

## 6. 交付前检查

交付前至少确认：

- `esp_idf_demo/main/config.h` 中的默认值符合当前文档
- `idf.py build` 已通过
- handoff 文档和设备端现状一致
- 压缩包不包含 `build/`、`managed_components/`、`.venv/`、`tmp/`
